# Campus Second-Hand Trading Platform

## Project Description
Campus Second-Hand Trading Platform is a web-based system designed for college students to buy and sell second-hand items within the campus community. The goal of this project is to provide a simple and convenient platform where users can post products, browse available items, and manage their own listings more easily.

This project is a full-stack application with separate frontend and backend parts.

## Features
- User registration and login
- Browse product listings
- Search for products
- View product details
- Publish second-hand items
- Manage personal listings
- Save or favorite items
- Basic admin management functions

## Installation Instructions

1. Clone or download the repository.

2. Open the frontend project in Visual Studio Code or another editor.

3. Open the backend project in IntelliJ IDEA.

4. Set up the database connection if needed.

5. Make sure the required dependencies are installed before running the project.

## Execution Instructions
### Backend

Run the backend project in IntelliJ IDEA after finishing the database setup.

### Frontend

Open the frontend folder and run:

``` bush
npm install
npm run dev
```

If your project uses a different command, use the correct frontend start command.
